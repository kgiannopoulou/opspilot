# README media

Everything in this folder is generated by a script, so the demo can be re-recorded after any UI change.

| File | What | Made by |
|---|---|---|
| `opspilot-demo.gif` | 90-second walkthrough shown in the README (one frame per moment, ~1.3 MB) | `build_gif.py` from the recorded frames |
| `opspilot-demo.webm` | The same walkthrough as a real-time video | Playwright video recording |
| `../screenshots/hero-incident-brief.png` | Recruiter screenshot: the incident brief at 2× pixel density | Playwright element screenshot |

```bash
docker compose up -d                                         # the full stack
docker compose exec api python -m app.scripts.seed --reset   # fresh demo data: the payment incident is live
cd frontend && npx playwright test -c playwright.media.config.ts
cd .. && python docs/media/build_gif.py                      # needs Pillow
```

The script ([`frontend/tests/media/demo.spec.ts`](../../frontend/tests/media/demo.spec.ts)) signs in as an engineer,
files the ticket *"Payment screen throws timeout after login"*, follows the correlation to the live incident, re-runs
the AI investigation, walks through root cause → evidence → runbook → read-only query, opens the incident brief,
resolves the incident and ends on the audit trail. Captions are drawn into the page, so they appear in both the GIF and
the video. Nothing is mocked: it drives the same stack `docker compose up` starts.
